# Methodology

The proposed system follows the following workflow:

1. User enters a search query.
2. The query is preprocessed using NLP techniques such as tokenization, stop-word removal, and lemmatization.
3. The system identifies the user's search intent.
4. The query is reformulated using transformer-based language models and semantic similarity techniques.
5. The improved query is forwarded to the search engine.
6. Relevant search results are retrieved and displayed to the user.
