# Literature Review

## Paper 1
Generative Query Reformulation for Effective Ad Hoc Search

This paper introduces a neural approach for rewriting user queries to improve search effectiveness. It demonstrates that transformer-based query generation significantly improves retrieval performance.

---

## Paper 2
ConvGQR: Generative Query Reformulation for Conversational Search

The authors propose a context-aware query reformulation model designed for conversational search. The approach preserves user intent while generating more informative search queries.

---

## Paper 3
Automated Query Reformulation Based on Stack Overflow Query Logs

This research uses historical query logs and deep learning techniques to automatically improve search queries, particularly for technical information retrieval.

---

## Paper 4
Identifying Web Search Query Reformulation Using Concept-Based Methods

This paper presents concept-based methods to identify and classify query reformulations, providing a foundation for intelligent search query enhancement.
