# System Architecture

The system consists of six major modules:

1. User Interface
   Accepts the user's search query.

2. NLP Preprocessing
   Cleans and processes the input query.

3. Intent Detection
   Identifies the purpose of the search query.

4. Query Reformulation
   Generates an optimized query using NLP and transformer models.

5. Search Engine Integration
   Sends the improved query to the search engine.

6. Result Display
   Displays relevant search results to the user.
